# Base44 paste — READ THIS FIRST

## DEAD END — do NOT use URL fetch

Base44's fetcher runs batch .txt URLs through a **markdown filter** that:
- Escapes `_` `*` `[` `|` as `\_` `\*` `\[` `\|`
- **Strips JSX tags** (`<Route>`, `<button>`, etc. become blank lines)
- Breaks template literals and image src

**Writing fetched content would destroy the app.** Only **direct paste into chat** works (like your 7 clean files).

## DO NOT USE
- `base44-paste-batches/BASE44-BATCH-*.txt` via URL fetch
- GitHub raw URLs to `.txt` wrapper files

## USE — direct chat paste

```bash
cd ~/restorebraine
git pull origin cursor/apple-privacy-plist-bacf
npm run base44:export-chat
```

Opens **`base44-paste-chat/`** — 34 messages, 64 remaining files.
